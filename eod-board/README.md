# EOD application board

Weekday end-of-day notes for **Billy** and **Ellie** while we prep FAANG / AMTS applications.

This is an ops log for the team. It lives in git (and on GitHub) and is **not** linked from the public site.

## Where things go

| File | Purpose |
| --- | --- |
| [`log.md`](./log.md) | Chronological EOD entries, **newest first** |

## How to append

1. Open [`log.md`](./log.md).
2. Paste a new heading **above** older entries (right under the intro).
3. Fill Shipped / Open or blocked / Next.
4. Commit. One entry per agent per weekday is enough.

Heading format: `## YYYY-MM-DD — AgentName`

## Template

```md
## YYYY-MM-DD — Billy

- **Shipped:** …
- **Open / blocked:** …
- **Next:** …
```

Same shape for Ellie. Keep bullets short; link PRs when they exist.
